# Lazy-globals trial rejected; accepted runtime restored

The lazy per-Interpreter fallback-map trial is **rejected**. The paired `string_dict_get` diagnostic ran at **0.865456×** accepted-control speed, with all seven pairs below 1×; the six settled ratios range from 0.848936× to 0.885403×. Other callback rows were mixed. Full correctness and the unchanged 11-case, 21-repeat, 5-warmup, 10% fixed gate passed, but that does not erase the separate regression. The [trial report](interpreter-lazy-globals-trial-20261008.md) retains all results and selected official comparisons; none establishes an overall gain or a new full 97-case result.

The [evidence manifest](data/interpreter-lazy-globals-trial-20261008-manifest.json) preserves all 560 paired timings, seven pair ratios per row, raw control/candidate logs, terminal validation, fixed-gate results, official JSON and warnings, and all 40 candidate-validation source files. No rejected engine or test implementation is part of this documentation checkpoint. Source snapshots under the evidence archive are records of the trial, not live implementation changes.

Proposal scratch copies use normalized LF text. Their hashes can differ from the actual working bytes compiled for the trial: the compiled C++ registration is pinned as `a58811867318b8fc58350a4c340757fbda467f30b27f7bd0a7544112d54c1cbf`, and the working lazy test helper as `d7573bee561b650583c955518df3e33f2d41afb957b4b5cc0abea7f10bf903a8`. The archive retains those actual bytes and the original proposal provenance separately. Restoration required exact accepted SHA-256 equality; LF-normalized equivalence alone was not accepted as proof of recovered bytes.

The [restoration receipt](data/interpreter-lazy-globals-restoration-20261008.json) records `accepted_source_and_live_release_restored`: the accepted 35-file source inventory and six pre-trial input files, including their overlapping entries, match their pinned hashes. The rejected lazy helper and registration were removed from the live trial. All **140 accepted Release files** were restored at the unchanged `build-repro/main-verify-20261006/Release/xlang3.exe` run location. The rejected **171-file** Release archive is preserved under `build-repro/controls/rejected-lazy-globals-trial-20261008` for diagnosis. The accepted source checkpoint remains `184b36fa4b4a85ab1a9e36d2090a9b8af574a92f`.

The 140-file accepted control did not include 31 additional files in the Release directory. Those files retain rejected-build bytes; restoration does **not** establish that every diagnostic executable or C++ test binary was rebuilt. Before configured C++ tests are run, rebuild `xlang3_interpreter_tests`, `xlang3_runtime_value_tests`, `xlang3_sdk_stream_call_tests`, and `xlang3_graph_process_tests` in the existing build directory. Other excluded diagnostic executables are not approved test inputs. No additional runtime, fixture, benchmark, or build was executed to prepare this outcome note.
