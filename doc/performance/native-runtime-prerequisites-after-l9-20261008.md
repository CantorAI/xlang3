# Runtime prerequisites after the rejected L9 trial

L9 was rejected by its declared performance-control rule, and its exact historical S8 source and Release files were restored. The [unchanged L9 report](native-entry-layout-l9-rejected-20261008.md) records the paired result and restoration. The plain-sort interval includes 1, so rejection is not evidence of a confirmed slowdown. This publication adds correctness evidence and source diagnosis; it does not publish a new engine win or full-suite refresh.

Two fresh CPython 3.14.7 versus preserved-S8 checks found existing semantic failures. Both reference managers ran one isolated CPython child followed by one preserved-S8 child, with byte-exact split stdout/stderr, a 120-second child limit, no retry, and unchanged source/control hashes. Their MSBuild-name allowance applies only to these untimed correctness checks; it did not admit a worker for any timed L9 measurement.

S8's later frame-context and numeric dictionary groups were not reached. In particular, the Bool/Double first-key and integer-subclass equality groups have no S8 runtime result in this capture. Their strict CP-passed source and expected bytes are retained without relaxed assertions. Proposed repairs are not included or represented as validated.

The [inspection directory](data/l9-runtime-prerequisites-inspection-20261008/) holds the exact tested sources, expected transcripts, executed capture managers, and a bounded reference-metadata record. These are inspection copies, not live registered tests or a portable standalone reproduction package. The receipts retain the original absolute paths and complete historical input pins; publication does not rewrite those records.

The next performance target is source-only. The [DictSet diagnosis](data/l9-runtime-prerequisites-inspection-20261008/dict-set-int64-official-source-diagnosis-20261008.md) identifies the unchanged official BPE decoder comprehension: 1,024 distinct integer keys trigger 523,776 linear existing-entry checks in the current VM handler. Retained IR confirms the DictSet route. Merely redirecting it to the existing runtime setter would still bypass stored integer-subclass equality, so numeric correctness and ownership/reentry prerequisites come first. This establishes reachable code and quadratic complexity, not a measured share of BPE time or an overall speedup. Python pickle memo writes use SetItem; no pickle gain is inferred.
