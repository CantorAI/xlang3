This directory contains the pure-Python package facade and schema declarations
from the `python/pydantic_core` directory of the `pydantic-core` 2.50.1 source
distribution. The native `_pydantic_core` extension is supplied by xlang3's
`pydantic_core._pydantic_core.x3pkg` package instead. See
`../PYDANTIC_CORE_LICENSE.txt` for the upstream MIT license.
